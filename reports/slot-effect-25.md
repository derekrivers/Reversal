# R25-B — slot effect `006d0980`

The complete 473-byte local body is now mapped. It has 141 x86 instructions, 19 local branches, nine direct calls to four callees, 14 direct nonframe writes and one `RET 16`. Every original PE instruction address, operand and explicit memory width matches the independently restored checkpoint-24 Ghidra export. The control-flow graph reaches all 141 instruction starts. [The site census](../evidence/slot-effect-25-sites.json) pins the PE body at raw file offset `0x2d0980`; addresses below are virtual. The executable SHA-256 is `0c78e7da6d0bcb4603fa179449bbe6d1b6b5e1c627a22c445d14d489bd9bff86`.

`ECX` is the match pointer; the four stack arguments are signed low-byte kind, signed low-byte severity, target pointer and optional other pointer. The function cleans 16 argument bytes and has no useful return value established. The existing native name and comment remain appropriate; [the findings proposal](../evidence/slot-effect-25-findings.json) upgrades its existing semantic entry from `boundary-mapped` to `contract-supported` after independent review, with zero new distinct functions and no native annotation change.

## Ordered local behavior

1. The throttle reads signed16 `match+0xf639`. Above 3, it draws `R(counter)` at `006d099d`. A nonzero result triggers `R(500)` at `006d09ae`; a nonzero second result returns immediately. The routine then rejects counters above 6 at `006d09be`, even if the first throttle draw was zero. Rejected calls can therefore consume RNG.
2. Admitted calls with kind >=0 invoke `0062be00` at `006d09ed`, passing target `+0x69` and pointers to the two low-byte arguments. That callee may modify kind, severity and external records; its transitive effects are not certified here. Kind `-1` bypasses it. At `006d09f8`, target `+0x55` is overwritten with the other pointer, including null. Nonnull other has its signed16 `+0x31` decremented by 10 at `006d09fd`, with 16-bit wrap.
3. The post-merge signed severity above 50 sets target byte `+0x1c=1` and subtracts severity squared from float32 target `+0x4d` at `006d0a12..006d0a23`. Severity at most 50 converts half the squared value to an integer, draws `R(bound)` at `006d0a41`, subtracts the float32 form of that result from target `+0x4d`, converts half that float32 result to a second bound and draws again at `006d0a6c`. It writes the second result to float32 `+0x59` and halves float32 `+0xd5`. The original constants at `00968968` and `00968f18` are both 0.5. No severity RNG occurs on the above-50 branch.
4. A resulting target float below 5000 sets match byte `+0x8eb5` and target bytes `+0x1d/+0x1c` to 1 at `006d0aa1..006d0aaa`. Otherwise the routine compares against `7100 + 25*signed8(*(target+0x6d)+0x2d)`. The middle branch calls `007160e0(5)` and sets the match latch and target `+0x1d`; the high branch calls `007160e0(3)` and sets those flags only if the first severity draw float is at least 500 and target `+0x1c` is already nonzero. The callee writes target byte `+0x2b`, but its full transitive contract is outside this lane.
5. The common tail clamps target float32 `+0x4d` to 1..10000 at `006d0b0b..006d0b3f`. It increments signed16 match `+0xf639` at `006d0b4d` whenever `+0x8eb5` is nonzero, including a latch set *before* this call. This function does not clear that latch on entry.

The RNG/callee order and all direct write sites are recorded in [findings](../evidence/slot-effect-25-findings.json). Static mapping does not validate the unexecuted paths or the transitive callees.

## Original-entry TypeScript comparison

[The oracle](../evidence/slot-effect-25-oracle.json) executes the original body from `006d0980` through `RET 16` in Unicorn 2.1.4 for 144 synthetic cases. They use kind `-1`, severities 51/75/127, input floats 1/500/4000/6000, counters -3/0/3, either latch value and null or nonnull other. The resulting float stays below 5000, so the original path makes no callee call. The [TypeScript reconstruction](../reconstruction/slot-effect-severe.ts) matches every final exposed field, the order and values of all external writes, and stack cleanup. The oracle also checks callee-saved registers. Its 8,568 steps cover 65 instruction starts, and its SHA-256 is `26ffaca654946f429188fb39b97c176af10399163cf88ac242735cb0b4d6f66f`.

The [negative checks](../evidence/slot-effect-25-negative.json) show that optimized Python accepts the pinned inputs while rejecting a modified PE and changed native operand width. A disposable resealed export also reaches and fails the operand-width comparison itself. The TypeScript checker rejects both a one-bit float-result mutation and reordered writes. The normal and optimized extractor outputs match; the retained research suite passed. The Python scripts do not rely on `assert` for integrity.

The bounded oracle does not cover the counter throttle RNG, kind merge, lower-severity RNG or `+0x2b` setter. `006d0980` remains one dependency in the larger `006cfe10` and action33 path; no complete shot or match outcome is implied.
