## Local contract

`ECX` is the match pointer. The function reads the low byte of its one four-byte stack argument after saving `EBX`, `EBP`, `ESI`, and `EDI`. It processes side 0 and side 1 in that order on **every** call. It then returns the cached side-1 pointer from match `+0xf5a2` if the selector byte equals 1; every other byte value returns side 0 from `+0xf59e`. `EAX` may be zero. `RET 4` discards the stack argument. `ECX` and the four saved registers are preserved; `EDX` is scratch. The function has no callee or RNG call.

For each side, a nonzero cache pointer is dereferenced at slot `+0x19`. A negative **signed byte** clears the cache; a nonnegative value retains it and bypasses that side's scan. No ownership, side-membership, tactical-word, or slot `+0x2b` test is repeated for a retained cache.

An empty cache scans 20 slots at stride `0x1be`, starting at match `+0x4796` for side 0 or `+0x6a6e` for side 1. It selects the **first** slot whose signed `+0x19` index lies in 0..10 and whose indexed tactical word equals 1. The tactical pointer is read from match `+0x8ebc + 4*signed8(slot+0x27)`; the word is read at `table + 2*index`. After a direct selection, the loop still visits the remaining slots to test reserve candidates, but cannot replace the cached direct slot.

Independently, the loop remembers the **last** reserve candidate with signed slot `+0x1a` in 0..10, tactical word 1 at that index, raw slot `+0x19 == 0xfe`, and raw slot `+0x20 == 0xff`. A reserve is used only when no direct slot was selected. The fallback scans the same 20 slots and caches the **first** slot whose signed `+0x19` is nonnegative. If a reserve was remembered, it copies the active slot's raw `+0x19` byte to the reserve's `+0x1a` and saves the reserve's old `+0x1a`. Then, whether or not a reserve exists, it tests the active slot's tactical word at that saved index (zero without a reserve). Only when that word is 1 does it replace the active slot's `+0x19`. The reserve's `+0x1a` write has already happened even if this final tactical test fails. If all 20 active indices are negative, the cache remains zero.

The only direct match/slot writes are cache clear/select at `+0xf59e` and `+0xf5a2`, reserve `+0x1a`, and fallback active `+0x19`. The [site evidence](../evidence/keeper-selector-29-sites.json) records all 10 store instructions and their widths. Signed slot `+0x27` has no local range guard, and a nonzero cached pointer has no local pointer validity guard beyond dereferencing `+0x19`. Those are caller/state obligations.

## Original-entry validation

The [oracle](../evidence/keeper-selector-29-oracle.json.gz) runs the pinned original instructions from entry to `RET 4` under Unicorn 2.1.4. Synthetic 64 KiB match memory, 4 KiB tactical tables and a 4 KiB stack are mapped without aliases; inputs cover cache hits, invalidation, direct selection, first-wins behavior, reserve/fallback reassignment, missing active slots, signed and sentinel guards, and selector bytes 0, 1 and 2. The 315 cases execute 154,779 x86 instructions and cover **all 155 instruction starts and all 190 local CFG edges**. The oracle retains mode IDs, register snapshots, instruction addresses, ordered match/table memory events, and SHA-256 digests of the entire final match, table and stack regions. No original table or game-memory bytes are retained.

The [headless TypeScript model](../reconstruction/keeper-selector-29.ts) and [checker](../reconstruction/check-keeper-selector-29.ts) match all 315 original-entry returns, 37,269 ordered match/table read/write events, the three full-region memory digests per case, the preserved-register/`ECX` contract, and `ESP + 8` after return. Full stack bytes account for the four saved register pushes. The checker runs under Node 24 and is registered in `npm run check`. The model intentionally represents this local, mapped-memory domain; it is not a safe general pointer API.

The [negative checks](../evidence/keeper-selector-29-negative.json) regenerate identical static/oracle bytes under normal and `python -O`, reject a changed PE, and reject an independently resealed native operand and exact-old annotation. The gzip writer normalizes Python/zlib OS bytes `03` and `0a` to the retained `ff` header; the privacy check rejects those alternative valid gzip envelopes, optional filenames and JSON whitespace. The [privacy check](../evidence/keeper-selector-29-privacy.json) enforces the synthetic input schedule and restricts per-case retained memory to three digests. `npm run check` passes with Node v24.19.0. These checks validate local behavior under synthetic mapped state; they do not prove the producer lifecycle, live cache validity, complete shot outcome, or a match result.
