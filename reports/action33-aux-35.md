## Auxiliary storage and first dependencies

In `00828110`, `0082849a` loads global staff count `00ae2364`; `0082849f` copies it to auxiliary count `00ae2d10`. Zero EBP is established at setup entry, but opaque preceding calls and setup completion are not executed here.

The allocator wrapper `00944e46..00944e57` pushes runtime DWORD `00de3008`, forwards its caller's size to `00944e58`, cleans its two arguments and returns with plain RET. Its inner allocator, runtime/heap initialization and actual allocation result are unresolved in this unit. A synthetic pointer returned in EAX would skip these dependencies. Both allocation-request windows therefore stop before calling it.

On the new-setup success branch, ESI receives the returned allocation and EDI the staff array `00ae23bc`. `0082854e` and `00828556` store DWORD `-1` at auxiliary `+0/+4`; `0082855d` clears byte `+8`. The selected range then reaches date comparisons and `00417c10`, followed by `008285b6 -> 0054cdb0`. The wider original listing also contains conditional random and staff/date work. The loop's selected tail advances auxiliary pointer by `0x4f`, staff pointer by `0x6e`, reloads global staff count, and loops at `00828753`. These selected instructions are static observations, not an executed table initializer or proof that unselected fields are initialized.

This separates allocation/default state from populated contract indices. R12's subsequent `004c7560` reserves manager rows and publishes a nonnegative row index into auxiliary DWORD `+0` at `004c788e` only after source eligibility and the earlier scalar/date work. Constructing an array of defaults or inserting a matching row would not establish that original producer path. ## Independent receiver and ABI

The load path passes incoming EDI to the constructor; its file-state provenance is not closed. The auxiliary base and receiver are separate dependencies, and neither may be synthesized to advance the lookup.

These are selected static stores after the OS/diagnostic region, not executed initialization. After global date-helper calls, a nonzero entry stack argument can call `004db5c0` at `004c74c4`; this identifies a further load dependency, not a recovered loader contract. There is no native constructor export in the pinned input, so these constructor observations are explicitly **PE-only static decode**, not native comparison or entry-to-return validation.

The contiguous PE decode of `004c74f0..004c7553` tests and releases members `+0/+c/+28`, then conditionally calls `0068d040` and free on members `+34/+38`. ## Executed scope and reproduction

The [extractor](../scripts/extract_action33_aux_35.py) executes **18 original interior allocation-request windows, 99 instruction steps**: new setup `0082849a..pre-008284ad` and load `0082af53..pre-0082af61`, each with nine explicitly synthetic DWORD counts. These include zero, ordinary positive values, multiplication overflow, and high-bit values; they establish request arithmetic, not valid database counts or successful allocations. The new window writes only the auxiliary count and outgoing size; the load window writes only the outgoing size. Complete nonstack and stack snapshots are independently checked, including neighbouring bytes. Neither window is an original function entry or return. The base and receiver globals remain loader-zero and no auxiliary records are written.

The private state manifest is pinned to SHA-256 `b338531e13c4626c151a5538fe871488698b056bfbb00fb9f9e669b82e4dd59a`, from checkpoint-28 archive `ab4bf204a86776c1a2e34caa6db9eb330665078446c5a7738e0d403fb415fb2a`; every manifest file is verified. **300 selected state instructions** are independently decoded with Capstone 5.0.7 and compared against their native operands. **350 constructor, destructor and allocator-wrapper instructions** are separately marked PE-only decode, with no native comparison. These are separate static evidence counts and neither is an execution-step count. The [oracle](../evidence/action33-aux-35-oracle.bin) contains synthetic observations, addresses, widths and digests. No original listing, table, string, executable bytes, native state or private memory page is retained.
