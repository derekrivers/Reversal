The pinned PE32 x86 specimen is 7,192,576 bytes, SHA-256 `0c78e7da6d0bcb4603fa179449bbe6d1b6b5e1c627a22c445d14d489bd9bff86`. Addresses below are **virtual addresses** unless explicitly marked as raw file offsets. The four complete bodies total **63 bytes and 24 Ghidra instruction rows**. All original PE bytes independently decode and every row matches the read-only checkpoint-21 Ghidra export by address, mnemonic and operand. This is static instruction mapping; it has no function-execution oracle or TypeScript reconstruction.

`005a8f60` contains only a return instruction. It does not set a success value or clear state. The return itself reads the saved return address from the stack and advances ESP four bytes. `0090d130` uses an immediate pointer rather than loading the string. Its caller decides whether to dereference or display the pointed-to bytes; the helper has no explicit data-memory read apart from the return's stack read, and makes no write.

`00945640` first saves EBP and allocates twelve stack bytes. At `00945646`, the bytes encode a WAIT-prefixed `FNSTCW` to the local word at EBP-2. Capstone splits this into `WAIT` and `FNSTCW`; Ghidra renders one `FSTCW` row. A separate `WAIT` follows at `0094564a`. The body copies the original control word to AX and executes `OR AH,0x0c`, setting x87 rounding-control bits 10 and 11 to binary 11, which selects rounding toward zero. It installs that modified word, executes `FISTP qword ptr [EBP-0x0c]` (storing an integer and popping ST(0)), restores the saved control word, and loads the low/high dwords into EAX/EDX before `LEAVE; RET`. All explicit memory writes are to its frame. The ordinary path restores the control word; exceptional control flow, status-word flags, NaN/out-of-range results and caller precision state need a numeric x87 oracle and are not claimed here.

`00945934` pushes zero twice and then reads the original argument from `[ESP+0xc]` at its now-adjusted stack pointer. Thus its call to `00945956` supplies `(original_arg,0,0)` in stack order. It executes `ADD ESP,0xc` after the call, then plain `RET`. On an ordinary callee return with the expected stack discipline, EAX is passed through and the wrapper leaves the caller's original argument for caller cleanup. `00945956` itself is outside this assignment; its global writes, imports, return behavior and result meaning remain open. The wrapper has no direct global-data store or RNG call.

The read-only R22-B caller export for `006ceb90` contains 13 direct calls to `00945640` and two each to `0090d130`, `005a8f60` and `00945934`. Its separate checkpoint-21 export manifest SHA-256 is `2001cb0b2f047ddd573fd17ae5c0e89ebefa24f4f224a8bcf4bb023c04cc61dc`, with assembly SHA-256 `279700bcaae733b4537327bfa34cc5b38d89fe9ebe1d74830f330b794694bee7`. Those call sites establish local dependency only; branch feasibility, ordered caller effects and any connected selection result belong to R22-B. There are no conditional branches in these four callees, one direct call, four plain returns, zero direct RNG calls and zero direct nonframe data stores.
